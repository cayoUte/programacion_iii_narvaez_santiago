# Programación III

## Autor

**Santiago Narvaez**

## Descripción

Repositorio correspondiente a la asignatura **Programación III**, enfocado en el desarrollo de aplicaciones web modernas utilizando **JavaScript, TypeScript, ReactJS y NestJS**.

El curso aborda el desarrollo completo de una aplicación web, desde la estructura y presentación del frontend hasta la construcción de un backend robusto, incluyendo bases de datos, autenticación, consumo de APIs, envío de correos y gestión de archivos.

## Contenidos

### 1. Fundamentos Web (Frontend)

Introducción a las tecnologías fundamentales del desarrollo web del lado del cliente:

- **HTML**
  - Estructura de páginas web
  - Elementos y etiquetas
  - Formularios
  - Buenas prácticas

- **CSS**
  - Estilos y diseño
  - Selectores
  - Modelo de caja
  - Diseño responsive
  - Flexbox y Grid

- **JavaScript**
  - Variables y tipos de datos
  - Funciones
  - Manipulación del DOM
  - Eventos
  - Consumo de APIs

- **TypeScript**
  - Tipado estático
  - Interfaces y tipos
  - Clases y módulos
  - Buenas prácticas
  - Preparación para el uso de frameworks

### 2. Backend con NestJS

Desarrollo de la lógica del servidor y construcción de APIs:

- Arquitectura modular de NestJS
- Controladores y servicios
- Bases de datos
- TypeORM / Prisma
- Modelos, migraciones y operaciones CRUD
- Validaciones
- Autenticación con JWT
- Consumo de APIs
- Envío de correos
- Configuración SMTP
- Correos transaccionales
- Confirmación de registro
- Subida y gestión de archivos
- Almacenamiento local y en la nube
- Gestión y validación de archivos

### 3. Frontend con ReactJS

Construcción de interfaces web modernas y responsivas:

- Componentes y estado
- Rutas y navegación
- Consumo de APIs mediante Axios / Fetch
- Manejo de formularios
- Organización y buenas prácticas
- Integración con servicios backend

### 4. Estilos y frameworks CSS

Aplicación de diferentes alternativas para el diseño de interfaces:

- CSS puro
- CSS Modules
- Material UI
- Ant Design
- Bootstrap
- Tailwind CSS
- Diseño responsive
- Sistemas de componentes
- Personalización de interfaces

## Objetivo del curso

Desarrollar aplicaciones web completas, partiendo de los fundamentos del frontend y avanzando hacia un backend robusto con bases de datos, autenticación, envío de correos y gestión de archivos, aplicando tecnologías actuales y buenas prácticas de desarrollo.
